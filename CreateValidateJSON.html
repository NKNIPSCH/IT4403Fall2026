Part A: Convert a Message to JSON

The message information can be represented as a JSON object using name and value pairs.

{
    "to": "Alex",
    "from": "Jordan",
    "heading": "Reminder",
    "body": "Don't forget our meeting tomorrow."
}

This JSON contains four properties. Each property name and text value is enclosed in double quotation marks, and commas separate the name/value pairs.

Part B: Convert a Collection to JSON

The book collection can be represented using a books array. Each item in the array is a separate JSON object containing the title, author, and price of a book.

{
    "books": [
        {
            "title": "Web Development Basics",
            "author": "Maya Lee",
            "price": 29.99
        },
        {
            "title": "Modern JavaScript",
            "author": "Daniel Kim",
            "price": 34.50
        },
        {
            "title": "Understanding JSON",
            "author": "Sofia Patel",
            "price": 24.95
        }
    ]
}

The square brackets create the books array, while the curly braces define each individual book object.

JSON Validation

Both JSON structures were checked to make sure they follow valid JSON syntax.

  • Property names are enclosed in double quotation marks.
  • Text values are enclosed in double quotation marks.
  • Numeric values are written without quotation marks.
  • Commas correctly separate properties and array items.
  • Curly braces are used for objects.
  • Square brackets are used for arrays.
  • Both JSON structures are syntactically valid.
